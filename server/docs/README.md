# Docs

This folder is a placeholder for project documentation you may want to generate for submission or handoff purposes:

- `SRS.pdf` — Software Requirements Specification
- `API-documentation.pdf` — Full REST API reference (see `server/routes/` for every endpoint; all routes are prefixed with `/api`)
- `database-schema.pdf` — ER diagram of the Mongoose models in `server/models/`
- `usecasediagram.png`, `classdiagram.png`, `sequencediagram.png`, `flowchart.png` — UML diagrams
- `presentation.pptx` — Project presentation deck

These are documentation artifacts, not application code, so they're left for you to generate (e.g. via draw.io, Postman's doc generator, or Claude) to match your submission requirements.
